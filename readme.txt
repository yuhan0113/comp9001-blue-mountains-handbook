Blue Mountains Handbook
Personalised Bushwalking & Local Guide

PROJECT OVERVIEW
Blue Mountains Handbook is an offline Python application that helps users find a Blue Mountains walk suited to their mood, available time, scenery preference and comfortable difficulty.

The project includes 18 walks and information about 14 Blue Mountains towns and areas. Users can receive personalised recommendations, browse walks, explore local town information and save recommendation reports.

Primary assessor-friendly version (CLI):
    python3 main.py

Optional Tkinter GUI:
    python3 gui.py

The GUI uses Python's built-in tkinter/ttk modules and may need to be run locally outside Ed's terminal environment.

Keep these files together:
    main.py
    gui.py
    data_loader.py
    recommendations.py
    trails.csv
    locations.csv

Tests:
    python3 -m unittest discover -v

Final result: 51 tests passed.
